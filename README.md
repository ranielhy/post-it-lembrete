# Post-it Lembrete

Aplicativo Linux de post-its coloridos, independentes e sempre visíveis.

## Executar

```bash
npm install
npm start
```

Os lembretes são salvos automaticamente na pasta de dados do usuário do Electron.

## Gerar instaladores

```bash
npm run dist
```

Os pacotes AppImage e `.deb` serão criados em `dist/`.
